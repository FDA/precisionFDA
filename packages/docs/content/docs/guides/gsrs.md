The [Global Substance Registration System (GSRS)](https://precision.fda.gov/ginas/app/ui/) is integrated into precisionFDA and provides a standardized way to identify substances used in medicinal products. Use the resources below to learn how to work with GSRS.

## External documentation

- [FDA GSRS User Manual (PDF)](https://gsrs.ncats.nih.gov/downloads/Substance%20Registration%20-%20October%202019.docx) — Official FDA user manual covering GSRS concepts, workflows, and substance registration procedures.
- [GSRS User Guide (GitHub Wiki)](https://github.com/ncats/gsrs3-main-deployment/wiki/User-Guide) — Maintained user guide for GSRS 3.x, hosted by NCATS on GitHub.
